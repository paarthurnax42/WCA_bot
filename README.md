# WCA Bot — Трекер воды и калорий

Telegram-бот для расчёта дневных норм воды и калорий с учётом веса, роста, возраста, активности и погоды. Позволяет логировать потребление воды, еды и тренировок, а также визуализировать прогресс через графики.



##  Возможности

-  Расчёт индивидуальных норм воды и калорий
- Учёт погоды через OpenWeatherMap API (жаркая погода → +500 мл воды)
- Поиск калорийности продуктов через многоступенчатый поиск:
  1. Перевод названия через MyMemory API
  2. Поиск в USDA FoodData Central (официальная база Минсельхоза США)
  3. Резервный поиск в OpenFoodFacts
- Графики потребления воды и калорий, начинающиеся с 00:00
- Персонализированные рекомендации по оставшемуся лимиту калорий

## Запуск локально

1. Установите Python 3.10+
2. Создайте виртуальное окружение:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux/Mac
   venv\Scripts\activate     # Windows
3. Установите зависимости:
    ```bash 
    pip install -r requirements.txt

4. Создайте файл .env на основе .env.example и заполните своими ключами:
    BOT_TOKEN — токен от @BotFather
    OPENWEATHER_API_KEY — ключ от OpenWeatherMap
    USDA_API_KEY — ключ от USDA FoodData Central (опционально)
Запустите бота:
    ```bash 
    python bot.py
